# homebrew-tap

personal homebrew formulae.

## install

```sh
brew tap mihaicrisan04/tap
brew install <formula>
```

or in one shot:

```sh
brew install mihaicrisan04/tap/<formula>
```

## formulae

| formula | description |
| --- | --- |
| [airdrop](https://github.com/mihaicrisan04/airdrop) | AirDrop files and URLs to nearby Apple devices from the terminal |
